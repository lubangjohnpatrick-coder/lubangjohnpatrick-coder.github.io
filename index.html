      AACE Guide

      What every AACE Creation document means and how to complete it

      How a project is created

      Every project starts at AACE Creation. Complete the five submission documents below in order — when they are all marked Done, the file is ready to move to Pre Bidding Request. Tick them off on any project's details panel, and use ✨ AI Draft to get an executive-quality starting text.

      1

      Justification Support

      The business case that answers why. Explain the current limitation, the operational or financial impact, the proposed intervention, the benefits, and the cost/payback. Finance and management read only this document to decide whether the CAPEX moves forward.

      💡 Draft it instantly below in your company's house format (from the Buggy Carts / Block Cutter samples) and save it to the project.

      Drafts are saved to the selected project. Use 👁 Open panel to jump straight to its details.
      2

      Scope of Work

      Defines what will be delivered: the deliverables, inclusions and exclusions, site conditions, interfaces with existing lines, installation, commissioning and acceptance criteria. Engineering uses this to evaluate bids.

      💡 Draft it instantly in the company's clause format (Machine/Equipment Delivery · Services and Warranty · Commissioning and Training).

      Drafts are saved to the selected project as its Scope of Work. Use 👁 Open panel to jump straight to its details.
      3

      Technical Operating Requirements

      The how it must perform specification: capacity, materials of construction, utility demands, product compatibility, safety, hygiene/cGMP, and compliance with plant standards. This becomes the technical basis for evaluation and trials.

      💡 List measurable requirements (e.g. ≥ 3 t/hr, stainless contact parts) so the Technical Evaluation is objective.

      4

      Pre Bidding Request

      Formal request to start sourcing. With the three documents above approved, Procurement prepares and releases the inquiry to bidders.

      💡 In the app this is the first status change — select Proponent → Pre-Bidding Request once all documents are Done.

      5

      CEPG Checklist

      The Capital Expenditure Project Guide completeness check: confirms every required attachment (justification, SOW, TOR, cost estimates, approvals routing) is present and correctly named before the file leaves the plant.

      💡 Keep this marked Doing until every attachment has an owner and a completed box in the checklist.

      ✓

      Then the approval trail begins

      Once complete, the project follows the tiered approval matrix (Plant Manager → IETS → Supply Chain → Finance → Corporate), which this dashboard tracks automatically stage by stage, percent by percent.

      💡 Watch the What to Do? page daily — it tells you the fastest next action and draft a follow-up email for whoever holds the file.
